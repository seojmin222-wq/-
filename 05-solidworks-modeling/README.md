# SolidWorks 역설계 모델링·제3각법 도면화 및 조립 설계 – 복합 필렛 형상 재현 + 롤러 지지 구조물 조립

## 개요
3D 설계 수업에서 완성 도면과 3D 참조 이미지만 주어진 하우징형 부품 2종(타원형 돔 형상, 클로버형 4엽 형상)을 SolidWorks로 역설계하고, 제3각법 2D 도면까지 직접 작성한 뒤 3D 프린팅으로 실물 검증까지 완료했습니다. 이와 함께 롤러/캐스터 지지 구조물을 구성하는 부품(휠, 지지 암 2개, 베이스 플레이트, 부싱, 볼트류)을 전부 직접 모델링하고 SolidWorks Assembly 기능으로 조립해 분해도(Exploded View)까지 완성한 프로젝트입니다.

- **기간**: [2026.05.12 ~ 2026.05.27]
- **참여 형태**: 개인 (수업 과제)
- **담당 역할**: 도면 해석부터 부품 모델링, 조립 설계, 2D 도면화, 출력 검증까지 전 과정 직접 수행

## 배경 및 문제 정의
3D 설계 수업에서 다양한 필렛(R1~R300, 2D/3D 필렛 구분)과 챔퍼 각도(20°~115°)로 구성된 하우징형 부품 2종의 완성 도면·3D 참조 이미지만 주어지고, 이를 동일하게 재현해야 하는 과제였습니다. 모델링 과정 자체가 제공되지 않아 형상을 스스로 해석하고 재구성해야 하는 역설계 방식이라 난이도가 있었습니다. 이와 별도로 롤러/캐스터 지지 구조물 과제에서는 완성된 조립체 이미지만 보고 이를 구성하는 개별 부품(휠, 지지 암, 베이스 플레이트, 부싱, 볼트 등)을 전부 직접 설계·모델링한 뒤 조립까지 재현해야 했습니다.

## 사용 기술 / 툴
- 3D CAD: SolidWorks (스케치, 돌출, 필렛, 쉘 등 형상 특징 모델링)
- 조립 설계: SolidWorks Assembly (메이트 구속조건 적용, Exploded View 분해도 작성)
- 도면화: 제3각법 2D 도면 작성 (치수·필렛 규격·각도 기입)
- 실물 검증: 3D 프린팅

## 작업 프로세스
![참조 이미지](images/05-reference.png)

참조 이미지 분석 → 형상 특징(feature) 순서 설계 → 부품별 3D 모델링(스케치-돌출-필렛-쉘) → 제3각법 2D 도면화 → 3D 프린팅 출력 → 도면-모델-실물 형상 정합성 검증 → 롤러/캐스터 지지 구조물 부품 개별 모델링 → 조립(Assembly) 및 메이트 구속 → 분해도(Exploded View) 작성

## 주요 구현 내용

### 1) 참조 형상 분석 및 역설계 모델링
참조 이미지의 곡면·필렛 형상을 분석해 스케치-돌출-필렛-쉘 등 형상 특징(feature) 순서를 스스로 설계했습니다. 첫 번째 부품은 8-R3, 4-R3, R35~R250 등 부위별로 다른 필렛 십수 개를 구분 적용했고, 2D 필렛과 3D 필렛의 차이를 구분해 정확히 재현했습니다. 100°/115°/70° 경사각과 오프셋(4-Offset 8) 형상까지 세부 치수에 맞춰 모델링했습니다. 두 번째 부품은 4방향 대칭 클로버 형상 보스와 Ø20 홀 4개, Ø40 원형 시트, R3~R300 범위의 필렛, 20°/100° 챔퍼각을 갖는 형상으로, 대칭 구속과 패턴 기능을 활용해 재현했습니다.
![3D 모델링 결과](images/05-3d-model.png)

### 2) 제3각법 2D 도면화
완성한 두 부품의 3D 모델을 각각 제3각법 기준 2D 도면(척도 1:1)으로 변환하고, 치수·필렛 규격·각도를 전부 기입했습니다.
![제3각법 도면](images/05-drawing.png)

### 3) 3D 프린팅을 통한 실물 검증
완성 모델을 3D 프린터로 출력해 도면-모델-실물 간 형상 일치 여부를 직접 검증했습니다.
![3D 프린팅 출력물](images/05-print-result.png)

### 4) 롤러/캐스터 지지 구조물 조립 설계
베이스 플레이트, 지지 암(브래킷) 2개, 휠(롤러), 부싱 2개, 볼트류까지 조립체를 구성하는 부품을 전부 개별로 직접 모델링했습니다. 이후 SolidWorks Assembly 환경에서 동심·일치 등 메이트 구속조건을 적용해 조립을 완성하고, Exploded View(분해 단계) 기능으로 부품 간 결합 순서와 구조를 보여주는 분해도까지 작성했습니다.
![조립체 분해도](images/05-assembly-exploded.png)
![조립체 완성 모델](images/05-assembly-render.png)

## 결과 및 성과
- 참조 도면과 동일한 형상의 부품 2종 3D 모델 및 제3각법 2D 도면 완성
- 3D 프린팅 출력물로 형상 정합성까지 확인 완료
- 롤러/캐스터 지지 구조물의 전 부품을 직접 모델링하고 조립·분해도까지 완성

## 회고 / 배운 점
스스로 생각지 못했던 제도 요소가 많다는 것을 깨달았고, 하나의 형상을 구현하는 데 고려해야 할 점이 생각보다 많다는 것을 체감했습니다. 이 과정에서 공간 감각을 다시 훈련하게 됐고, 하나의 대상을 여러 각도에서 더 깊이 관찰하고 여러 방법으로 시도해보며 가장 효율적인 표현 방식을 찾는 습관을 갖게 됐습니다. 특히 조립 설계 과정에서는 부품 간 구속조건을 어떻게 설정해야 의도한 대로 조립되고 움직이는지 고민하며, 개별 부품 설계와는 다른 조립 설계 특유의 사고방식을 체득할 수 있었습니다.
