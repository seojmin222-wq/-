# SolidWorks 역설계 모델링 및 제3각법 도면화 – 복합 필렛 형상 재현 + 3D 프린팅 검증

## 개요
3D 설계 수업에서 완성 도면과 3D 참조 이미지만 주어진 하우징형 부품을 SolidWorks로 역설계하고, 제3각법 2D 도면까지 직접 작성한 뒤 3D 프린팅으로 실물 검증까지 완료한 프로젝트입니다.

- **기간**: [2026.05.12 ~ 2026.05.27]
- **참여 형태**: 개인 (수업 과제)
- **담당 역할**: 도면 해석부터 3D 모델링, 2D 도면화, 출력 검증까지 전 과정 직접 수행

## 배경 및 문제 정의
3D 설계 수업에서 다양한 필렛(R1~R250, 2D/3D 필렛 구분)과 챔퍼 각도(100°, 115°, 70°)로 구성된 하우징형 부품의 완성 도면·3D 참조 이미지만 주어지고, 이를 동일하게 재현해야 하는 과제였습니다. 모델링 과정 자체가 제공되지 않아 형상을 스스로 해석하고 재구성해야 하는 역설계 방식이라 난이도가 있었습니다.

## 사용 기술 / 툴
- 3D CAD: SolidWorks (스케치, 돌출, 필렛, 쉘 등 형상 특징 모델링)
- 도면화: 제3각법 2D 도면 작성 (치수·필렛 규격·각도 기입)
- 실물 검증: 3D 프린팅

## 작업 프로세스

![참조 이미지](images/05-reference.png)

참조 이미지 분석 → 형상 특징(feature) 순서 설계 → 3D 모델링(스케치-돌출-필렛-쉘) → 제3각법 2D 도면화 → 3D 프린팅 출력 → 도면-모델-실물 형상 정합성 검증

## 주요 구현 내용

### 1) 참조 형상 분석 및 역설계 모델링
참조 이미지의 곡면·필렛 형상을 분석해 스케치-돌출-필렛-쉘 등 형상 특징(feature) 순서를 스스로 설계했습니다. 8-R3, 4-R3, R35~R250 등 부위별로 다른 필렛 십수 개를 구분 적용했고, 2D 필렛과 3D 필렛의 차이를 구분해 정확히 재현했습니다. 100°/115°/70° 경사각과 오프셋(4-Offset 8) 형상까지 세부 치수에 맞춰 모델링했습니다.

![3D 모델링 결과](images/05-3d-model.png)

### 2) 제3각법 2D 도면화
완성한 3D 모델을 제3각법 기준 2D 도면(척도 1:1)으로 변환하고, 치수·필렛 규격·각도를 전부 기입했습니다.

![제3각법 도면](images/05-drawing.png)

### 3) 3D 프린팅을 통한 실물 검증
완성 모델을 3D 프린터로 출력해 도면-모델-실물 간 형상 일치 여부를 직접 검증했습니다.

![3D 프린팅 출력물](images/05-print-result.png)

## 결과 및 성과
- 참조 도면과 동일한 형상의 3D 모델 및 제3각법 2D 도면 완성
- 3D 프린팅 출력물로 형상 정합성까지 확인 완료

## 회고 / 배운 점
스스로 생각지 못했던 제도 요소가 많다는 것을 깨달았고, 하나의 형상을 구현하는 데 고려해야 할 점이 생각보다 많다는 것을 체감했습니다. 이 과정에서 공간 감각을 다시 훈련하게 됐고, 하나의 대상을 여러 각도에서 더 깊이 관찰하고 여러 방법으로 시도해보며 가장 효율적인 표현 방식을 찾는 습관을 갖게 됐습니다.
