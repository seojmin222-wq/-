# 큐타임 위반 예방 자동 라우팅 & O-ring 열화 예지보전 시스템 – PLC·SCADA·DB·분석 4-Layer 통합

> 🚧 진행 상태: 마무리 단계 (PLC 최종 동작 검증 및 3D 프린팅 마무리 진행중)

## 개요
반도체 공정에서 웨이퍼 큐타임(Q-Time) 초과 시 로트 폐기, 챔버 O-ring 열화 미감지로 인한 웨이퍼 불량이 발생하지만 이를 자동 감지·대응하는 통합 시스템이 부재했습니다. 4인 팀 프로젝트로 하드웨어부터 PLC·SCADA·DB·데이터분석까지 아우르는 4-Layer 파이프라인 구축을 목표로 진행했습니다.

- **기간**: [2026.08 ~ 진행중]
- **참여 형태**: 팀 프로젝트 (4인, 팀장)
- **담당 역할**: 팀장 — 전체 일정관리, MPS 하드웨어 재구성, PLC/서보 배선, 3D 프린팅 부품 설계 총괄 및 팀원 PLC 로직·iFIX 구현 조율

## 배경 및 문제 정의
반도체 공정에서 웨이퍼 큐타임 초과 시 로트가 폐기되고, 챔버 O-ring 열화를 미리 감지하지 못해 웨이퍼 불량으로 이어지는 문제가 있었습니다. 이를 자동으로 감지·대응할 수 있는 통합 시스템이 없어, 현장제어부터 데이터 분석까지 아우르는 4-Layer 파이프라인을 직접 구축하기로 했습니다.

## 사용 기술 / 툴
- PLC/서보: MELSEC PLC, MR-J5 서보모터
- HMI: GOT HMI
- SCADA: iFIX (OPC-UA 연동)
- DB: SQLite
- 데이터 분석: Python (pandas), LSTM 시계열 분석
- 하드웨어: MPS 설비 재조립, 3D 프린팅 부품 설계·제작
- 협업/일정관리: 주 단위 팀 공유 문서 트래킹

## 시스템 구성 (4-Layer 아키텍처)

![시스템 아키텍처](images/03-architecture.png)

| Layer | 구성 요소 | 역할 |
|---|---|---|
| 1. 현장제어 | MELSEC PLC, MR-J5 서보, GOT HMI | 로트·압력·큐타임 데이터 수집, 위험등급·열화 판정, 위험 로트 우선 이송, 현장 경보 표시 |
| 2. SCADA | iFIX (OPC-UA) | 큐타임 히트맵, O-ring 상태 게이지, KPI 대시보드 실시간 시각화 |
| 3. DB | SQLite | 로트별·시간대별·챔버별 이력 자동 적재 |
| 4. 분석 | Python(pandas), LSTM | 병목 구간 분석, 압력 강하율 기반 열화 패턴 도출, 최적 보전 주기 산출 |

## 주요 구현 내용

### 1) 프로젝트 일정관리 (팀장 역할)
주 단위로 지난주 완료 업무와 이번주 목표를 팀 공유 문서로 트래킹했습니다. PLC 로직·iFIX(팀원 담당)와 하드웨어(본인 담당) 등 역할을 분담하고 진행 상황을 조율했습니다.

### 2) 4-Layer 시스템 아키텍처 설계
MELSEC PLC가 로트·압력·큐타임 데이터를 수집해 위험등급·열화를 판정하고, MR-J5 서보 기반 컨베이어가 위험 로트를 우선 이송하며, GOT HMI가 현장 경보를 표시하도록 설계했습니다. OPC-UA로 iFIX SCADA에 큐타임 히트맵·O-ring 상태 게이지·KPI 대시보드를 실시간 시각화하고, SQLite DB에 로트별·시간대별·챔버별 이력을 자동 적재했습니다. 이후 Python(pandas)으로 병목 구간을 분석하고, 압력 강하율 기반 LSTM 시계열 분석으로 열화 패턴을 도출해 최적 보전 주기를 산출하는 4-Layer 파이프라인을 설계했습니다.

### 3) MPS 하드웨어 재조립 및 부품 재설계
챔버 설치를 위해 분배·공급 실린더 위치를 조정하고 재조립했으며, 미사용 센서 배선을 정리하고 고장난 솔레노이드를 진단했습니다. 카메라-PLC 연동 오류(바코드 인식 불량)의 원인을 파악해 수정했습니다. 실린더 위치 조정으로 발생한 간섭 문제는 구조 변경으로 해결했고, 길이가 맞지 않게 된 분배막대는 3D 프린팅으로 재설계·재제작했습니다.

![하드웨어 재조립](images/03-hardware.png)

### 4) PLC·서보 트러블슈팅
PLC 2대(각 MPS 담당)를 포트·IP 주소로 구분해 PC 1대에서 동시 제어했습니다. 서보 알람 발생 시 배선 미결선을 확인해 수정했고, 리미트센서 신호 불량으로 인한 서보 정지는 센서 교체로 해결했습니다. I/O 센서판에서 센서 간 오동작 간섭을 발견해 미사용 센서를 제거함으로써 문제를 해소했습니다.

### 5) 3D 프린팅 반복설계
한 번에 출력이 불가능한 부품을 조립식 구조로 재설계해 분할 출력·조립했습니다. 챔버-오링 접합부 구조를 개선해 조립성을 확보했고, 웨이퍼 진입 오차는 공급 위치·속도 조정으로 해결했습니다.

![3D 프린팅 부품](images/03-3dprint-parts.png)

### 6) 컨베이어 연동
PLC-컨베이어 구동용 24V→12V 컨버터 배선·전압 세팅 절차를 직접 수립하고, 래더 로직으로 컨베이어 시작/정지 제어를 구현했습니다.

## 결과 및 성과
- 4-Layer(현장제어-SCADA-DB-분석) 파이프라인 설계 및 하드웨어 재구성 완료
- 서보·센서·PLC 통신 관련 트러블슈팅 4건 이상 원인 진단 및 해결
- 3D 프린팅 부품 재설계·재출력을 3회 이상 반복해 조립 완성도 확보
- 현재 PLC 최종 동작 검증과 3D 프린팅 마무리 단계로, 프로젝트 완주를 앞두고 있음 (진행중)

## 회고 / 배운 점
하드웨어(챔버·실린더 설계) - 제어(PLC/서보) - 모니터링(iFIX SCADA) - 데이터 분석(Python/LSTM)을 아우르는 4-Layer 시스템을 팀장으로 리드하며 스마트팩토리 전체 파이프라인 설계 역량을 확보했습니다. 매뉴얼대로 되지 않는 하드웨어 문제(센서 간섭, 배선 누락, 출력 실패)를 원인 단위로 쪼개 진단하고 반복 설계로 해결하는 문제해결력을 체득했습니다. 또한 주간 단위 일정관리로 팀원 간 작업 의존성을 조율하는 리더십 경험도 쌓을 수 있었습니다.
